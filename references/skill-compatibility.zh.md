# 首次技能兼容性体检

[English](skill-compatibility.md)

Birdview 在环境首次配置时执行一次轻量体检。它从用户级和项目级技能目录发现 `SKILL.md`，记录重名和明显的触发元数据问题；语义冲突仍由 Agent 阅读相关技能正文后判断。

运行：

```sh
node <skill-root>/scripts/birdview.mjs skills audit --project <project-root> --write <project-root>/.birdview/compatibility-audit.json
```

报告是确定性的，包含检查目录、相对路径、名称、描述、SHA-256 摘要和简单元数据标记。不存在或无法读取的目录不在覆盖范围内。它不会执行技能、推断优先级或禁用文件。重名是发现冲突，不代表两份技能一定相互矛盾。

扫描后，读取名称或触发描述重叠技能的正文，比较激活策略、写入权限、确认门槛、产物所有权和明确范围。按安装技能附带的报告契约填写人类结论，写明任务场景、用户影响、置信度、双方当前文件的原文证据和具体建议。将关系分为兼容、可排序、潜在冲突或未决。用户指令和宿主优先级仍然最高。不能仅凭这份报告修改其他技能。机器报告和 Markdown 报告与项目产物一起保存，并披露过期、未引用或不完整的覆盖范围。
